# Image Matching Game

A fun and interactive memory matching game built with Python and Pygame. This project was originally developed as a team effort and is now being maintained and enhanced as a personal project.

## 🎮 Game Description

The Image Matching Game is a classic memory card game where players need to match pairs of identical images. The game features:
- Multiple difficulty levels
- Engaging background music
- Smooth animations
- Intuitive user interface
- Score tracking

## 🛠️ Technologies Used

- Python
- Pygame
- Custom GUI elements

## 📋 Requirements

- Python 3.x
- Pygame library

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/Image-Matching-Game.git
```

2. Install the required dependencies:
```bash
pip install pygame
```

3. Run the game:
```bash
python Home.py
```

## 🎯 How to Play

1. Launch the game by running `Home.py`
2. Click on the "PLAY" button to start
3. Select your preferred difficulty level
4. Match pairs of identical images by clicking on them
5. Try to complete the game with the fewest moves possible

## 📁 Project Structure

- `Home.py` - Main game launcher and home screen
- `Menu.py` - Game menu and difficulty selection
- `GUI/` - Contains all graphical assets
- `Sounds/` - Contains game audio files
